# 对接你自己的软件（也是 Cursor 写的）——怎么呈现、怎么接

你这边产品已经测通：**USB 直连 + 手机注入**主通路可用。下一步是让「你的推流软件」直接往手机推，不必再点 Demo。

---

## 推荐呈现方式（给那边 Cursor 用）

**一个接口、两种通道，写进你软件的设置页：**

| 选项名（建议文案） | 含义 | 技术 |
|--------------------|------|------|
| **手机 USB 直连** | 数据线；低延迟 | 软件 → TCP `127.0.0.1:18765` BXMS → 本机「USB直连助手」→ 手机 |
| **局域网推流** | 同 Wi‑Fi | 软件照旧推 RTSP/MediaMTX；手机面板选「局域网」填电脑 IP |

设置页再加两行状态即可：
- 「助手已连接 / 未连接」（能否连上 18765）
- 「最近推送：视频帧 / 音频帧」

完整可复制提示词：`docs/ai-prompt-other-software-ingest.md`  
测法清单：`docs/delivery-plan-checklist.md`

---

## 你怎么跟「写自家软件的那个 Cursor」说

直接把这段丢给它（或把 `ai-prompt-other-software-ingest.md` 整份贴过去）：

1. 打开仓库里的 `tools/BxMediaSource/BxMediaSourceClient.cs` 当 SDK。  
2. 在你软件里加「推到手机」：连接 `127.0.0.1:18765`，按 Demo 顺序发 **H.264 + AAC**（画面和声音都要）。  
3. 用户电脑须先开 `tools/BxUsbDirect/BXFloat-USB直连助手.bat`。  
4. 手机：注 dylib，替换开，推流声音开。  
5. 断线只丢帧、自动重连，不要堵采集线程。  
6. 保留原有网络推流路径，不要删。

样例可抄：`tools/BxMediaSource/ProgramDemo.cs`（循环推 + 自动重连）。

## 分工（避免两边 Cursor 互相改乱）

| 仓库 / 对话 | 负责 |
|-------------|------|
| **本仓库（手机注入 + 助手）** | 收端、替换、融合、稳定性；**接口冻结：BXMS + 18765** |
| **你的推流软件仓库** | UI「推到手机」、编码 H.264/AAC、调用 Client、重连 |

本仓库先把「点直播不卡」加固好；对接以文档 + Client 为准，不必改注入逻辑。
